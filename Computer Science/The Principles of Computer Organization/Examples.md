# 存储系统

## 存储器

### 例题：存储器芯片数量计算

**题目**

某计算机主存容量为64KB，其中ROM区为4KB，其余为RAM区，按字节编址。现要用2K×8位的ROM芯片和4K×4位的RAM芯片来设计该存储器，则需要上述规格的ROM芯片数和RAM芯片数分别是？

**解答**

1. ROM区：容量为4KB，即 $4\text{K} \times 8$ 位。ROM芯片为 $2\text{K} \times 8$ 位，位数已满足，只需进行字扩展：

$$\text{ROM芯片数} = \frac{4\text{K} \times 8}{2\text{K} \times 8} = 2$$

2. RAM区：容量为 $64\text{KB} - 4\text{KB} = 60\text{KB}$，即 $60\text{K} \times 8$ 位。RAM芯片为 $4\text{K} \times 4$ 位，需同时进行字扩展和位扩展：
   - 位扩展：$8 / 4 = 2$ 片构成一组 $4\text{K} \times 8$ 位；
   - 字扩展：$60\text{K} / 4\text{K} = 15$ 组。

$$\text{RAM芯片数} = \frac{60\text{K} \times 8}{4\text{K} \times 4} = 15 \times 2 = 30$$

**结论**：需要ROM芯片 **2** 片，RAM芯片 **30** 片。

### 例题：DRAM芯片的引脚数

**题目**

某容量为256M的存储器，由若干4M×8位的DRAM芯片构成，该DRAM芯片的地址引脚和数据引脚总数是？

**解答**

> 注意：所求的是单个DRAM芯片的引脚数，与存储器总容量256M无关。

1. 地址线：芯片有 $4\text{M} = 2^{22}$ 个存储单元，需要22位地址。但DRAM采用**地址复用**技术，行地址和列地址分两次通过同一组引脚送入，因此地址引脚数减半：

$$\text{地址引脚数} = \frac{22}{2} = 11$$

2. 数据线：芯片字长为8位，故数据引脚为 **8** 根。

3. 总数：

$$11 + 8 = 19$$

**结论**：该DRAM芯片的地址引脚和数据引脚总数为 **19**。

> 易错点：若忽略DRAM的地址复用，会误算为 $22 + 8 = 30$。SRAM不采用地址复用，若为同规格SRAM芯片，则为30。

### 例题：顺序存储器与交叉存储器的带宽

**题目**

设存储器容量为32字，字长64位，模块数 $m=4$，分别用顺序方式和交叉方式进行组织。存储周期 $T=200\text{ns}$，数据总线宽度为64位，总线传送周期 $\tau=50\text{ns}$。问顺序存储器和交叉存储器的带宽各是多少？

**解答**

以连续读出 $m=4$ 个字为例进行比较。

1. 读出的信息总量：

$$q = 64\text{位} \times 4 = 256\text{位}$$

1. 顺序存储器：各字依次读出，每个字都需要一个完整的存储周期，所需时间为

$$t_1 = mT = 4 \times 200\text{ns} = 800\text{ns} = 8 \times 10^{-7}\text{s}$$

   带宽为

$$W_1 = \frac{q}{t_1} = \frac{256\text{位}}{8 \times 10^{-7}\text{s}} = 3.2 \times 10^{8}\text{位/s}$$

1. 交叉存储器：4个模块分时启动，每隔一个总线传送周期 $\tau$ 启动一个模块，所需时间为

$$t_2 = T + (m-1)\tau = 200\text{ns} + 3 \times 50\text{ns} = 350\text{ns} = 3.5 \times 10^{-7}\text{s}$$

   带宽为

$$W_2 = \frac{q}{t_2} = \frac{256\text{位}}{3.5 \times 10^{-7}\text{s}} \approx 7.3 \times 10^{8}\text{位/s}$$

**结论**：顺序存储器的带宽为 $3.2 \times 10^{8}$ 位/s，交叉存储器的带宽约为 $7.3 \times 10^{8}$ 位/s，交叉存储器的带宽约为顺序存储器的2.3倍。

## Cache

### 例题：组相联映射的主存地址划分

**题目**

一个4路组相联的Cache共有64块，主存共有8192块，每块32个字节。则主存地址的标记、组号和块内地址各是多少位？

**解答**

1. 主存地址总位数：主存容量为 $8192 \times 32\text{B} = 2^{13} \times 2^{5}\text{B} = 2^{18}\text{B}$，按字节编址，故主存地址共 **18** 位。

2. 块内地址：每块 $32\text{B} = 2^5\text{B}$，故块内地址为 **5** 位。

3. 组号：4路组相联，Cache组数为

$$\frac{64}{4} = 16 = 2^4$$

   故组号为 **4** 位。

4. 标记：

$$18 - 4 - 5 = 9$$

   故标记为 **9** 位。

**结论**：主存地址格式为

| 标记 | 组号 | 块内地址 |
| :--: | :--: | :------: |
| 9位  | 4位  |   5位    |

### 例题：Cache/主存系统的效率和平均访问时间

**题目**

CPU执行一段程序时，Cache完成存取的次数为1900次，主存完成存取的次数为100次，已知Cache存取周期为50ns，主存存取周期为250ns，求Cache/主存系统的效率和平均访问时间。

**解答**

1. 命中率：

$$h = \frac{N_c}{N_c + N_m} = \frac{1900}{1900 + 100} = 0.95$$

2. 主存与Cache的访问时间之比：

$$r = \frac{t_m}{t_c} = \frac{250\text{ns}}{50\text{ns}} = 5$$

3. 访问效率：

$$e = \frac{1}{r + (1 - r)h} = \frac{1}{5 + (1 - 5) \times 0.95} = \frac{1}{1.2} \approx 83.3\%$$

4. 平均访问时间：

$$t_a = \frac{t_c}{e} = \frac{50\text{ns}}{1/1.2} = 50\text{ns} \times 1.2 = 60\text{ns}$$

   也可直接由命中率计算验证：

$$t_a = h \cdot t_c + (1 - h) \cdot t_m = 0.95 \times 50\text{ns} + 0.05 \times 250\text{ns} = 47.5\text{ns} + 12.5\text{ns} = 60\text{ns}$$

**结论**：Cache/主存系统的效率约为 **83.3%**，平均访问时间为 **60ns**。

### 例题：二级Cache对处理器性能的影响

**题目**

假设处理器基本的CPI为1.0，所有访问在一级Cache中均命中，时钟频率为5GHz。假定主存访问时间为100ns，其中包括缺失处理时间。设一级Cache中每条指令缺失率为2%。如果增加一个二级Cache，命中或缺失访问的时间都是5ns，而且容量大到使访问主存的缺失率减为0.5%，问处理器速率提高了多少？

**解答**

1. 时钟周期：

$$T = \frac{1}{5\text{GHz}} = 0.2\text{ns}$$

2. 主存缺失代价（以时钟周期计）：

$$\frac{100\text{ns}}{0.2\text{ns}} = 500 \text{ 个时钟周期}$$

3. 只有一级Cache时的总CPI：

$$CPI_1 = 1.0 + 2\% \times 500 = 1.0 + 10 = 11.0$$

4. 二级Cache访问时间（以时钟周期计）：

$$\frac{5\text{ns}}{0.2\text{ns}} = 25 \text{ 个时钟周期}$$

5. 增加二级Cache后的总CPI：
   - 一级Cache缺失（2%）时需访问二级Cache，代价为25个周期；
   - 二级Cache也缺失（全局缺失率0.5%）时还需访问主存，代价为500个周期。

$$CPI_2 = 1.0 + 2\% \times 25 + 0.5\% \times 500 = 1.0 + 0.5 + 2.5 = 4.0$$

6. 性能提升（时钟频率相同，指令数相同）：

$$\text{加速比} = \frac{CPI_1}{CPI_2} = \frac{11.0}{4.0} = 2.75$$

**结论**：增加二级Cache后，处理器速率提高到原来的2.75倍（即提高了175%）。

### 例题：Cache-主存-磁盘三级存储系统的平均访问时间

**题目**

某计算机的存储系统由Cache、主存和磁盘构成。Cache的访问时间为15ns；如果被访问的单元在主存中但不在Cache中，需要用60ns的时间将其装入Cache，然后再进行访问；如果被访问的单元不在主存中，则需要10ms的时间将其从磁盘中读入主存，然后再装入Cache中并开始访问。若Cache的命中率为90%，主存的命中率为60%，求该系统中访问一个字的平均时间。

**解答**

> 注意单位：Cache和主存的时间以 **ns** 计，磁盘时间以 **ms** 计，必须先统一单位再计算：
>
> $$10\text{ms} = 10 \times 10^{6}\text{ns} = 10^{7}\text{ns}$$
>
> （$1\text{ms} = 10^{3}\mu\text{s} = 10^{6}\text{ns}$）

主存命中率60%是指**Cache缺失的情况下**，在主存中找到的概率。访问分为三种情况：

| 情况 | 概率 | 所需时间 |
| :--: | :--: | :------: |
| Cache命中 | $0.9$ | $15\text{ns}$ |
| Cache缺失，主存命中 | $0.1 \times 0.6 = 0.06$ | $60 + 15 = 75\text{ns}$ |
| Cache缺失，主存也缺失 | $0.1 \times 0.4 = 0.04$ | $10^{7} + 60 + 15 = 10000075\text{ns}$ |

平均访问时间：

$$
\begin{aligned}
t_a &= 0.9 \times 15 + 0.06 \times 75 + 0.04 \times 10000075 \\
&= 13.5 + 4.5 + 400003 \\
&= 400021\text{ns} \approx 400\mu\text{s}
\end{aligned}
$$

**结论**：该系统中访问一个字的平均时间约为 **400021ns**，即约 **0.4ms**。

> 易错点：
> - **区分ns和ms**：$1\text{ms} = 10^{6}\text{ns}$。若误把10ms当作10ns，会得到 $13.5 + 4.5 + 0.04 \times 85 = 21.4\text{ns}$ 的错误结果。
> - 主存命中率是在Cache缺失前提下的**条件概率**，要乘以Cache缺失率0.1，而不能直接用0.6。
> - 磁盘缺失项虽然概率只有4%，但其时间比其他项大约5个数量级，因此平均时间几乎完全由它决定。

## 虚拟内存

### 例题：页式虚拟存储器的TLB地址变换

**题目**

某计算机主存地址空间大小为256MB，按字节编址。虚拟地址空间大小为4GB，采用页式存储管理，页面大小为4KB，TLB（快表）采用全相联映射，有4个页表项，内容如下表所示。

| 有效位 |  标记  | 页框号 | ...  |
| :----: | :----: | :----: | :--: |
|   0    | FF180H | 0002H  | ...  |
|   1    | 3FFF1H | 0035H  | ...  |
|   0    | 02FF3H | 0351H  | ...  |
|   1    | 03FFFH | 0153H  | ...  |

问对虚拟地址 03FF F180H 进行虚实地址变换的结果是多少？

**知识点：TLB表项各字段的含义**

TLB（Translation Lookaside Buffer，快表）是页表的高速缓存，存放最近用过的若干页表项。每个TLB表项主要包括：

| 字段   | 含义                                                         | 作用                                         |
| :----: | :----------------------------------------------------------- | :------------------------------------------- |
| 有效位 | 该TLB表项当前是否有效（1有效，0无效）                        | 有效位为0时，即使标记匹配也视为**TLB缺失**   |
| 标记   | 由虚页号产生，用来标识这一项对应**哪个虚页**                 | 与虚拟地址的虚页号（或其高位）比较，判断是否命中 |
| 页框号 | 该虚页所在的**主存物理页号**（实页号）                       | 命中后与页内地址拼接，得到物理地址           |
| ...    | 其他控制位，如修改位（脏位）、访问位、存取权限等             | 支持页面置换、写回和存储保护                 |

- **有效位**：系统刚启动、进程切换（TLB被刷新）或对应页被换出主存时，相应TLB表项的有效位会被清0，表示这一项内容已经作废。
- **标记**：它的长度取决于TLB的映射方式，原理和Cache的标记相同：
  - **全相联映射**：标记 = 完整的虚页号；
  - **组相联映射**：虚页号拆成"标记 + 组号"，标记 = 虚页号的高位，组号用来选组；
  - **直接映射**：虚页号拆成"标记 + 行号"，标记 = 虚页号的高位。
- **页框号**：也叫实页号、物理页号，位数 = 物理地址位数 − 页内地址位数。物理地址 = 页框号 ‖ 页内地址。

> 判断TLB命中的条件：**标记匹配 且 有效位为1**，两者缺一不可。

另：H表示Hex，十六进制

**解答**

1. 地址位数：
   - 虚拟地址空间 $4\text{GB} = 2^{32}\text{B}$，虚拟地址共 **32** 位；
   - 主存地址空间 $256\text{MB} = 2^{28}\text{B}$，物理地址共 **28** 位；
   - 页面大小 $4\text{KB} = 2^{12}\text{B}$，页内地址为 **12** 位。

2. 地址格式：
   - 虚页号：$32 - 12 = 20$ 位；
   - 页框号：$28 - 12 = 16$ 位（与表中4位十六进制的页框号一致）。

| 虚页号 | 页内地址 |
| :----: | :------: |
|  20位  |   12位   |

1. 拆分虚拟地址：12位页内地址恰好对应3位十六进制数，故

$$\text{03FF F180H} \Rightarrow \text{虚页号} = \text{03FFFH},\quad \text{页内地址} = \text{180H}$$

1. 查TLB：TLB采用**全相联映射**，标记即为完整的虚页号。将虚页号 03FFFH 与各项标记比较，与第4项匹配，且其有效位为1，**TLB命中**，得页框号为 0153H。

2. 拼接物理地址：

$$\text{物理地址} = \text{页框号} \,\Vert\, \text{页内地址} = \text{0153H} \,\Vert\, \text{180H} = \text{015 3180H}$$

**结论**：虚实地址变换的结果为 **015 3180H**（28位物理地址）。

> 易错点：
> - 第2项标记 3FFF1H 与虚拟地址"03FF F1"部分形似，但虚页号应取高20位 03FFFH，不能按4位一组随意切分；
> - 第1项标记 FF180H 与地址低位相同，但标记只与虚页号比较，与页内地址无关；
> - 若匹配项的有效位为0，则视为TLB缺失，需访问主存中的页表。

### 例题：分页虚存的地址变换与缺页判断

**题目**

在一个分页虚存系统中，用户虚地址空间为32页，页长1KB，主存物理空间为16KB。已知用户程序有10页长，若虚页0、1、2、3已经被分别调入主存8、7、4、10页中，请问虚地址0AC5H和1AC5H对应的物理地址是多少？（或报告缺页）

**解答**

1. 地址格式：
   - 页内地址：页长 $1\text{KB} = 2^{10}\text{B}$，为 **10** 位；
   - 虚页号：$32 = 2^5$ 页，为 **5** 位，虚地址共 $5 + 10 = 15$ 位；
   - 实页号：主存页数 $16\text{KB} / 1\text{KB} = 16 = 2^4$，为 **4** 位，物理地址共 $4 + 10 = 14$ 位。

| 虚页号 | 页内地址 |
| :----: | :------: |
|  5位   |   10位   |

| 实页号 | 页内地址 |
| :----: | :------: |
|  4位   |   10位   |

2. 页表（已调入部分）：

| 虚页号 |  0   |  1   |  2   |  3   |
| :----: | :--: | :--: | :--: | :--: |
| 实页号 |  8   |  7   |  4   |  10  |

3. 虚地址 0AC5H：展开为15位二进制并按"5位 + 10位"划分

$$\text{0AC5H} = \underbrace{00010}_{\text{虚页号}=2}\ \underbrace{10\,1100\,0101}_{\text{页内地址}=\text{2C5H}}$$

   查页表，虚页2在实页4（$0100$），拼接得

$$\text{物理地址} = 0100 \,\Vert\, 10\,1100\,0101 = 01\,0010\,1100\,0101 = \text{12C5H}$$

4. 虚地址 1AC5H：

$$\text{1AC5H} = \underbrace{00110}_{\text{虚页号}=6}\ \underbrace{10\,1100\,0101}_{\text{页内地址}=\text{2C5H}}$$

   虚页6在程序范围（0~9页）内，是合法地址，但不在已调入主存的0~3页中，**发生缺页**，需由操作系统将该页从磁盘调入主存后再进行地址变换。

**结论**：虚地址 0AC5H 对应的物理地址为 **12C5H**；虚地址 1AC5H 所在的虚页6未调入主存，**发生缺页**。

> 易错点：页内地址为10位，不是4的整数倍，**不能按十六进制每4位一组直接切分**，必须先展开成二进制，再按"5位虚页号 + 10位页内地址"划分。

### 例题：虚地址、物理地址位数与页表长度

**题目**

主存容量为4MB，虚存容量为1GB，则虚地址和物理地址各为多少位？如页面大小为4KB，则页表长度是多少？

**解答**

（按字节编址）

1. 虚地址位数：虚存容量 $1\text{GB} = 2^{30}\text{B}$，故虚地址为 **30** 位。

2. 物理地址位数：主存容量 $4\text{MB} = 2^{22}\text{B}$，故物理地址为 **22** 位。

3. 页内地址：页面大小 $4\text{KB} = 2^{12}\text{B}$，页内地址为 **12** 位。

4. 页表长度：页表为**每个虚页**设置一个页表项，因此页表长度等于虚页数：

$$\text{页表长度} = \frac{\text{虚存容量}}{\text{页面大小}} = \frac{2^{30}\text{B}}{2^{12}\text{B}} = 2^{18} = 256\text{K}$$

**结论**：虚地址 **30** 位，物理地址 **22** 位，页表长度为 $2^{18}$，即 **256K** 个页表项。

| 虚页号 | 页内地址 |
| :----: | :------: |
|  18位  |   12位   |

| 实页号 | 页内地址 |
| :----: | :------: |
|  10位  |   12位   |

> 易错点：**页表长度看虚存容量，而非主存容量**。页表以虚页号为索引，每个虚页对应一个页表项（无论该页是否已调入主存，未调入的由有效位标记）。若误用主存容量计算，会得到 $2^{22} / 2^{12} = 2^{10} = 1\text{K}$，这是**实页数**，而非页表长度。
