# 中央处理器：组成与基本工作过程

> 根据《计组_中央处理器-1.pdf》《计组_中央处理器-2.pdf》整理。本文聚焦 CPU 组成、指令周期、时序控制及控制器实现；具体内容以教材模型为准，不同 ISA/微体系结构的寄存器和时序可能不同。

## 1. CPU 在计算机中的位置

冯·诺依曼计算机的五个基本部件是**运算器、控制器、存储器、输入设备、输出设备**。CPU 通常由控制器与运算器构成：

- **控制器**：取出并分析指令，产生控制信号，协调 CPU、存储器和 I/O 之间的数据流。
- **运算器**：执行算术与逻辑运算，并根据结果更新状态标志。
- **数据通路**：寄存器之间、寄存器与 ALU 之间传送数据的路径。控制器决定数据从哪里来、经过何处、最终写入哪里。

CPU 的主要功能可归纳为：指令控制、操作控制、时间控制、数据加工和中断处理。

## 2. CPU 中的主要寄存器

| 寄存器 | 全称 / 作用 | 记忆要点 |
|---|---|---|
| PC | 程序计数器，保存下一条待取指令的地址 | 顺序执行时自动更新；转移指令可改写它 |
| IR | 指令寄存器，保存当前指令 | 操作码字段送入指令译码器 |
| AR | 地址寄存器，暂存当前访问的存储单元地址 | 保存“访问哪里” |
| DR | 数据缓冲寄存器，暂存从存储器读出、待写入存储器或 ALU 产生的数据 | 缓冲速度差异及数据传送 |
| 通用寄存器 | 暂存操作数和运算结果 | 数量随处理器而异 |
| AC | 累加寄存器，保存 ALU 运算结果或参与运算的数据 | 常见于简化 CPU 模型 |
| PSW | 程序状态字/状态条件寄存器 | 保存条件码和系统状态 |

常见条件码：**C**（进位/借位相关标志）、**V**（溢出）、**Z**（结果为零）、**N**（结果为负）。具体定义与指令集有关。

### 控制器与运算器

- 控制器常见组成：PC、IR、指令译码器、操作控制器、时序产生器。
- 运算器常见组成：ALU、累加寄存器、DR、PSW。
- **操作控制器**依据指令操作码、时序信号和状态反馈产生操作控制信号。
- **时序产生器**负责让控制信号按正确的时间先后顺序生效。

## 3. 指令执行与周期层次

存储程序计算机先将程序和数据放入内存，开始运行时把程序首地址送入 PC。CPU 反复取指、译码、执行，并形成后续指令地址。

| 名称 | 含义 | 层次关系 |
|---|---|---|
| 时钟周期（T 周期） | 处理操作的基本时间单位，也称节拍脉冲周期 | 最小时间单位 |
| CPU 周期（机器周期） | 在该课程模型中，完成一次内存读指令字所需的最短时间 | 通常含若干 T 周期 |
| 指令周期 | 取指、分析并执行一条指令所需总时间 | 通常含若干 CPU 周期，长度随指令变化 |

简化关系：`时钟周期 < CPU周期 < 指令周期`。这里的“小于”表示时间尺度上的包含关系；实际处理器可能有流水线、缓存等机制，不能简单把现代 CPU 完全等同于此模型。

## 4. 指令周期的公共步骤

一条指令的一般执行过程：

1. **取指**：PC 给出指令地址，读出指令并装入 IR；PC 更新以便顺序取下一条。
2. **译码/分析**：译码器识别操作码、操作数类型和寻址方式。
3. **执行**：按指令要求进行寄存器传送、ALU 运算、存储器读写或转移。
4. **检查中断**：有可响应请求时转入中断处理；否则进入下一条指令。

取指通常是指令间的公共操作。执行阶段的操作步骤数因指令而异；执行完成后也可能进行中断等公共处理。

### 示例模型：五种指令

假设指令地址为八进制，指令含义如下：

| 指令 | 语义 | 典型执行工作 |
|---|---|---|
| `MOV R1, R0` | `(R1) → R0` | 寄存器间传送 |
| `LAD 6, R1` | `M[6] → R1` | 读存储器操作数 |
| `ADD R1, R2` | `(R1)+(R2) → R2` | ALU 运算并写回 |
| `STO R2, (R3)` | `(R2) → M[(R3)]` | 存储器写入 |
| `JMP 101` | `PC ← 101` | 无条件转移 |

注：汇编操作数先后顺序及目的操作数位置由具体指令集定义；上表遵照课件中的简化模型。

## 5. 不同指令的周期差异

在课件模型中，取指阶段通常占一个 CPU 周期；执行阶段依指令而变化：

| 指令类别 / 例子 | 典型 CPU 周期数 | 执行阶段要点 |
|---|---:|---|
| RR 型：`MOV`、`ADD` | 2 | 取指 1 周期，寄存器传送或运算 1 周期 |
| 读存储器：`LAD` | 3 | 取指；送操作数地址并读数；数据装入目标寄存器 |
| 写存储器：`STO` | 3 | 取指；送存储器地址；将寄存器数据写入存储器 |
| 无条件转移：`JMP` | 2 | 取指；将目标地址装入 PC |

这些数字是给定教学模型的时序，不是所有处理器的固定规律。若存储器等待时间、指令长度或总线结构不同，周期数也会变化。

## 6. 方框图语言与微操作

- **方框**代表一个 CPU 周期，框内写该周期的数据通路操作或控制操作。
- **菱形**代表判别/测试；通常依附于前一个方框，不额外占用一个 CPU 周期。
- 数据传送常用 `X → Y` 表示把 X 的内容送入 Y；`M[地址]` 表示存储器该地址的内容。
- 同一周期可并行的操作必须满足数据通路资源允许且彼此不冲突。

例：`R1 → Y`、`R0 → X` 后，由 ALU 执行 `Y + X → R0`，表示 `(R1)+(R0)` 的结果写回 R0。具体能否合并到同一周期，取决于硬件通路和控制信号设计。

## 7. 时序与控制方式

一个 CPU 周期可细分为若干时序小段；课件示例使用 `T1–T4`。控制方式决定操作序列如何与时间协调：

| 控制方式 | 核心思想 | 优点 | 代价 / 局限 |
|---|---|---|---|
| 同步控制 | 指令操作按统一时钟/节拍安排 | 设计思路清楚、易协调 | 固定时序可能浪费时间；可使用统一或不定长机器周期 |
| 异步控制 | 操作按需进行，以部件“应答”作为结束条件 | 可减少等待与时间浪费 | 应答逻辑较复杂，操作序列不严格按固定周期推进 |
| 联合控制 | 大部分操作同步，难以预定完成时间的部分用应答信号 | 在统一时序与弹性之间折中 | 需要同时处理两类控制逻辑 |

## 8. 快速复习

- **PC 指向下一条指令，IR 保存当前指令，AR 保存地址，DR 暂存数据，PSW 保存状态。**
- 指令周期不等于 CPU 周期；复杂的访存指令通常比寄存器指令执行阶段更长。
- 控制器决定“做什么、何时做”；数据通路负责“数据怎么走”。
- 时序图题先按取指/执行分阶段，再逐周期列出数据流，最后核对总线与寄存器是否有冲突。
